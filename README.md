# NoteWise Study Buddy

Build a responsive web app called AI Study Buddy – Notes to Quiz using React, TypeScript, and Tailwind CSS.Create a clean, modern student dashboard with simple navigation and mobile-friendly design.Allow users to paste study notes or upload PDF files.Extract PDF text and provide an Analyze Notes button.Use Google Gemini AI to generate:exactly 5–6 bullet points.Quiz: exactly 5 MCQs, each with 4 options, correct answer, and explanation.exactly 3 terms with simple meanings.Allow users to attempt the quiz, submit answers, and view their score.include Clear Notes, Remove File, and Analyze Again buttons.Technical Requirements:Integrate Gemini securely through a server-side function.Store the API key in environment secrets, never frontend code.Add loading indicators, error handling, and input validation.Ensure PDF upload, text extraction, AI analysis, and every button work correctly.Do not display fake or hardcoded AI results.No login or paid database required.Build a fully functional application, not just a visual prototype. Test the complete process from uploading or pasting notes to displaying the summary, quiz, and key terms.
